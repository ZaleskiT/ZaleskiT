## About Me

I'm a full-stack developer finishing my degree at Arizona State University (graduating December 2026). I enjoy building practical web apps end to end, from Angular front ends to Node.js and .NET back ends and the databases behind them.

I got hooked on web development in grade school after working through Laura Lemay's *Teach Yourself Web Publishing with HTML in a Week*. Outside of code, I organize international Warhammer tournaments across the Asia-Pacific region, which is where my main project came from.

## Featured Projects

### Release the Beast

A tournament management web app for Warhammer Age of Sigmar team events. Teams register, players are matched up each round, scores are submitted, and final standings are posted automatically to Discord.

Frontend: Angular, Angular Material &nbsp;|&nbsp; Backend: NestJS, Discord.js &nbsp;|&nbsp; Data & Auth: Supabase (PostgreSQL, Discord OAuth)
